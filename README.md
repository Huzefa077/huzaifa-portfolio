# Huzaifa Sheikh - Portfolio

The source code for [huzaifasheikh.dev](https://huzaifasheikh.dev), a personal
portfolio showcasing my full-stack development projects, skills, education,
certifications, and experience.

## Technology

- Next.js and React
- TypeScript
- Tailwind CSS
- Static export deployed with GitHub Pages

## Local development

Install the Node.js version specified in `.nvmrc`, then run:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run type-check
npm test
npm run build
```

## Deployment

Pushes to `main` are validated and deployed through the GitHub Actions
workflow. The custom domain is configured as `huzaifasheikh.dev`.
